- `GET /customers/{id}/summary`
- `GET /customers/{id}/statement`
- `GET /estimates`
- `GET /estimates/{id}`
- `GET /estimates/{id}/pdf`
- `GET /payments`

## Authentication
- `POST /auth/login` is anonymous and returns a JWT plus user profile.
- `GET /auth/me` requires a bearer token.
- All business endpoints require bearer authentication.
- `GET/POST/PUT /users` and user deactivation require the Admin role.
- `POST /users/{id}/activate` requires the Admin role and reactivates an existing user without deleting the row.

Send the token as:
`Authorization: Bearer <token>`

## Customer Work Status
- `GET /customers/{customerId}/projects` returns all estimate-backed customer projects and current execution status.
- `GET /estimates/{estimateId}/work-status` returns the current execution status.
- `PUT /estimates/{estimateId}/work-status` updates status, progress, dates, and notes.
- `POST /estimates/{estimateId}/start-work` starts work and records the actual start date.
- `POST /estimates/{estimateId}/resume-work` resumes temporary stops without deleting stop history.
- `GET /estimates/{estimateId}/work-status-history` returns the stored timeline.

Statuses are `NotStarted`, `Scheduled`, `InProgress`, `TemporarilyStopped`, `PermanentlyStopped`, `Completed`, and `Cancelled`. Progress is constrained to `0..100`; completed work is always stored as `100%`. Stop states require an effective date and reason; permanent stop also requires confirmation. Admin and Staff can update; Viewer is read-only.

## Role Permissions
- `Admin`: unrestricted business and administration access.
- `Staff`: customer, estimate, payment, report, and export workflows.
- `Viewer`: authenticated GET/read-only access.
- Payment void requires Admin or Staff with `CanVoidPayments=true`.

Report query filters include `dateFrom`, `dateTo`, `customerId`, `customer`, `estimateStatus`, `paymentMethodId`, `hasOutstanding`, and `fullyPaid` where applicable.

## XLSX Exports
- `GET /exports/customers.xlsx`
- `GET /exports/customers/{customerId}/summary.xlsx`
- `GET /exports/customers/{customerId}/statement.xlsx`
- `GET /exports/estimates.xlsx`
- `GET /exports/payments.xlsx`
- `GET /exports/outstanding.xlsx`
- `GET /exports/fully-paid.xlsx`
- `GET /exports/monthly-collections.xlsx`

Export endpoints return real `.xlsx` workbooks generated by ClosedXML. They support the same report filters where applicable.
